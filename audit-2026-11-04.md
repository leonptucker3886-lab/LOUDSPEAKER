## Method (runtime-aware, not just static markup)

- `js/nav.js` **unconditionally injects** a sticky `.lnx` header (canvas logo + links) plus a
  `.lnq` quick-links row on every page that loads it. It does **not** duplicate footers: it
  appends quote art into an existing `<footer>`, or creates one `.ll-footer` if none exists.
- `js/bottom-nav.js` injects a fixed `nav.lbn` bottom bar (Top 5 first) on every page that
  loads it, **except** `/kids*` paths. It does not check for a static `.bottomnav`, so a
  static bar + the injector = two bottom bars — but no in-scope page currently has that combo.
- Classes: **canonical** = matches the homepage reference. **Duplicated** = two headers,
  footers, or bottom navs render. **Variant** = a different single chrome (usually the old
  injected `.lnx`/`.lbn` or a legacy static header). **Missing** = none.
  Overall = worst dimension, ranked duplicated > variant > missing > canonical.
- Contents API returns empty content for files over 1 MB, so `dating-profile.html`
  (3,896,362 bytes) was fetched via the git blob endpoint and classified normally.
  It is the only file over 1 MB besides `index.html` (968,546 bytes, under the limit).

## What changed since Oct 23 (135 pages → 168 files)

The headline moved, but the reference moved more. In October, nav.js-injected chrome **was**
the canonical reference, so injected pages counted canonical. The Oct 31 homepage redesign
moved the reference to static `.bar` + `.bottomnav` chrome, and the site did not follow:
102 in-scope pages still load `nav.js`, 82 still load `bottom-nav.js`, only 17 pages have a
static `.bar`, and only 3 carry the PRESENTS wordmark (`index.html`,
`games/snes/shelf/play.html`, `started-from-a-baby.html`). This is mostly a migration gap,
not new breakage — except the 12 double-header pages below, where static `.bar` was added
**without** removing the `nav.js` load, so two sticky headers render.

Mechanism tallies (in-scope): `nav.js` on 102 pages, `bottom-nav.js` on 82, legacy `.bnav`
bottom bars on 50, legacy `.llh` static headers on 18. The old `.gh` header clone is gone
(0 pages). No page has a duplicated bottom nav today — the Oct 23 `.bnav` + `.lbn` stacking
is fixed; the bottom-nav problem is now uniformity (132 variant), not doubling.
