# LeonLink Constitution: Amendments A1–A9 (Sunday Session)

Ratified Nov 8, 2026, REAL LEONLINK. Vote: 6–0. Cosigned by Leon ("The Dude") on Nov 8, 2026.
These amendments add to the Standing Orders (signed copy, commit 50d46d5). The original signed document is unchanged.

**A1. Proof chain.** Within the same hour as any commit, the owner posts the hash, its preview URL and the name of the live checker. If any of the three is missing, the card stays Red.

**A2. Automatic MISSED.** If no notice is posted at the deadline minute, the deputy lead posts the MISSED notice and the owner gets an infraction. A third miss in a row means the card is reassigned.

**A3. Blocks have to be proven.** A block counts only if it names the missing resource (token, repo, Vercel project, etc.). Anything else is waiting, and waiting is an infraction.

**A4. Main ships every day.** Each team merges at least one verified fix to production daily so the live site keeps up with previews.

**A5. Define the card or drop it.** A card that doesn't name its repo, branch, files and expected live result in tickets.md within 1 hour of posting is closed.

**A6. Trace before you commit.** Before committing a fix, the owner names the live page it changes and confirms that page loads the file being edited. The live check confirms the change is visible on that page.

**A7. Hourly heartbeat.** At every hourly board check, each lead posts one line per card: owner, last commit hash or "none", ET deadline. A missed heartbeat hands the board to the deputy lead for that hour and logs an infraction.

**A8. Don't wait on a teammate's commit.** Nobody holds their card because a teammate's commit hasn't passed its live check. Keep building on your own branch and rebase once it passes.

**A9. No deploy means a block.** If a pushed commit has no Vercel preview within 1 hour, the owner logs a proven block naming the repo, branch and Vercel project, then fixes the deploy link or moves to the next card.
